# 物流分拣机器人研发项目

具身智能研发助手协作项目，目标是完成物流分拣机器人的研发交付工作。

---

## 文件结构

```
project/
├── CLAUDE.md          ← Agent 执行手册（规则层，由用户维护）
├── STATUS.md          ← 进度快照（状态层，由 agent 维护）
├── DEVLOG.md          ← 开发日志
├── docs/              ← 产物文件夹
│   └── sub_project_1/ ← 子任务文档文件夹
└── README.md          ← 本文件
```

---

## 协作机制

| 文件 | 维护者 | 作用 |
|------|--------|------|
| `CLAUDE.md` | 用户 | 规则 / 工作方式 / 工程规范，agent 的入口锚点 |
| `STATUS.md` | Agent | 当前阶段、已完成工作、下一步、阻塞项 |
| `DEVLOG.md` | Agent | 关键事件流水账 |

每次新会话或 `/clear` 后，agent 自动读取 `CLAUDE.md` + `STATUS.md` 无损恢复状态。

---

## 设计原则

1. **状态外化**：agent 的记忆存在文件里，不依赖上下文
2. **人机分工**：agent 自驱执行，用户只在决策点介入
3. **context 节约**：重要信息落盘，用文件存储换 context 空间
4. **可观测**：STATUS.md 让用户随时了解 agent 进展
